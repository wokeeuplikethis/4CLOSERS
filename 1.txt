ВАЖНО:
Ты работаешь непосредственно в текущей папке проекта.

==================================================
1. STACK
==================================================

Используй:

- Next.js с App Router
- React
- TypeScript
- Tailwind CSS
- Motion for React / Framer Motion для анимаций
- Lucide React для иконок
- shadcn/ui там, где это действительно уместно
- PostgreSQL

6. АНИМАЦИИ И INTERACTION
==================================================

Сайт должен ощущаться ЖИВЫМ.

Используй Motion for React / Framer Motion.

Добавь:

- scroll reveal
- stagger animations
- parallax
- image scale при scroll
- разные скорости движения элементов
- плавное появление текста
- animated gradients
- subtle grain
- marquee / бегущие строки
- hover animations
- magnetic buttons
- cursor-follow effects на desktop
- плавные card hover effects
- scroll progress indicator
- sticky sections
- горизонтальные portfolio sections
- плавные city transitions
- transition текста при смене города
- transition изображений при смене города
- плавные page transitions

Можно использовать небольшие 3D/tilt эффекты для карточек, но только если они выглядят качественно.

НЕ перегружай сайт анимациями.

Главный принцип:

PREMIUM / CINEMATIC / SMOOTH

а не:

"как можно больше эффектов".

Обязательно поддержи:

prefers-reduced-motion

Для пользователей, которые отключили motion, анимации должны упрощаться или отключаться.
